# Материалы астероидов 00–50

Самостоятельный набор для Unity 6 / URP проекта. Существующие генератор локаций, сцены и обработка сида не изменены.

## Быстрое применение

1. Выберите астероид или корневой объект модели в Hierarchy.
2. Add Component → Asteroids → Material Applicator.
3. Material Number: номер из списка 0–50. Texture Scale: число повторов на размер модели (по умолчанию 2).
4. Нажмите «Применить к астероиду». При запуске компонент также применяет материал автоматически.

Работает с MeshRenderer и SkinnedMeshRenderer, включая дочерние объекты и несколько material slots. Все слоты заменяются выбранным материалом. Частицы и прочие типы Renderer пропускаются. Настройки каждого объекта хранятся в компоненте; материал общий, без создания его копий. Изменение номера в Play Mode требует кнопки «Применить» или SetMaterial.

Из кода:

```csharp
AsteroidMaterialLibrary.Apply(asteroidGameObject, 10); // Золото
AsteroidMaterialLibrary.Apply(asteroidGameObject, 49, 3f); // Ядро Бездны, 3 повтора
// Или для уже добавленного компонента:
asteroid.GetComponent<AsteroidMaterialApplicator>().SetMaterial(2);
```

Номер материала является сидом его процедурной текстуры. Сиды локаций библиотека не разбирает: интеграция с генератором остаётся отдельной задачей. Воспроизведение текстур: из папки проекта выполнить `node Tools/generate_asteroid_materials.cjs`. Сохраняются номера, рисунок и GUID. Генератор перезаписывает карты и .mat этого набора.

## Файлы

- Textures/: 204 PNG 1024×1024, по четыре карты для каждого номера.
- Resources/AsteroidMaterials/: 51 готовый .mat, имена 00.mat–50.mat. Не переименовывать числовые файлы: библиотека загружает их по номеру.
- Shaders/Triplanar.shader: физическое освещение URP, отражения, тени, трёхосевая проекция в локальных координатах модели.
- catalog.json: номера, названия, исходные описания, параметры и сид.
- SOURCE.md: исходный список.
- Preview.png: обзор текстур по порядку слева направо, сверху вниз; 9 материалов в строке, последняя строка содержит 45–50.

Карты: Color — цвет sRGB; Surface — линейная упакованная карта R=металличность, G=высота, B=окклюзия, A=гладкость; Normal — дополнительная normal map для использования в других шейдерах; Emission — цвет свечения sRGB. Шейдер набора рассчитывает рельеф из высоты Surface, а не из Normal. PNG и их .meta следует переносить вместе.

## Внешний вид

Процедурные фактуры с многоуровневым зерном, неровными прожилками и разной шероховатостью; без нарисованных бликов и теней. Для оценки металлов нужны свет и отражения среды (skybox / reflection probe). Отсутствие отражений может сделать металл слишком тёмным. Материал можно редактировать напрямую: Relief, Texture Scale, Emission Strength, Tint. Компонент нормализует проекцию по размеру mesh и переопределяет Texture Scale для объекта.

Наложение не требует UV или тангентов, следует за вращением модели. На стыках отдельных мешей возможны различия проекции, поскольку каждый меш нормализуется отдельно. Нажатие кнопки допускает Undo для назначений .mat; параметры проекции повторно выставляются компонентом при следующем применении/запуске. Property blocks сами по себе в сцене Unity не сериализуются.

Ограничения: лёд и стекло здесь непрозрачные поверхности со стеклянным блеском; внутренние пузыри и слои переданы поверхностной текстурой. Настоящие прозрачность, рефракция, искривление света, следы времени, объёмное внутреннее свечение и выступающие иглы требуют отдельных шейдеров/геометрии и не реализованы этим набором. Живой металл и Первоматерия имеют плавное движение проекции (Flow), без деформации геометрии. Предназначено для динамических астероидов; lightmap baking и отдельный DepthNormals pass не реализованы.

## Проверка

Проверены 51 .mat, ссылки на карты и размеры всех 204 PNG. Повторная генерация 00 даёт идентичный SHA-256. Библиотека, компонент и инспектор успешно скомпилированы против сборок Unity 6000.5.9f1. Проверка шейдера и рендера в Unity не завершилась: отдельный редактор остановился на лицензировании headless и запуске Package Manager до импорта. Поэтому рендер в вашем открытом редакторе требует визуальной проверки.
