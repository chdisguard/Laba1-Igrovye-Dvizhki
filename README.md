# Лаба1 Игровые Движки

Космическая игра на Unity: управление кораблём через консоль, процедурные залежи астероидов, добыча руды и торговля.

## Запуск проекта

1. Скачать репозиторий через **Code → Download ZIP** или `git clone`.
2. Установить через Unity Hub **Unity 6000.5.9f1** с модулем **Windows Build Support (Mono)**.
3. Добавить корневую папку репозитория в Unity Hub и открыть проект. При первом открытии требуется интернет для загрузки пакетов.
4. Дождаться импорта ассетов и открыть `Assets/Scenes/SampleScene.unity`.
5. Нажать **Play**.

В репозитории находятся `Assets`, `Packages` и `ProjectSettings`, включая `.meta` и зафиксированные версии пакетов. Кэш Unity, локальные логи и готовые сборки не требуются.

## Сборка Windows x64

В редакторе выбрать **Space → Build Windows x64**. Результат: `Builds/Windows/SpaceMining.exe`.

Или использовать Python 3.9+:

```console
python Tools/build.py --unity "C:/Program Files/Unity/Hub/Editor/6000.5.9f1/Editor/Unity.exe"
```

Можно также собрать `SampleScene` через **File → Build Profiles**, выбрав Windows x64. При распространении игры нужно передавать всю папку сборки вместе с `SpaceMining_Data`, `UnityPlayer.dll` и `MonoBleedingEdge`.

Если на старой Windows инструмент UnityLinker завершается с `AreShadowStacksEnabled() || UseSpecialUserModeApc()`, повторить команду с флагом `--linker-compat`. Он временно применяет обход совместимости к UnityLinker, сохраняет оригинал в `Logs/UnityLinker.exe.original` и восстанавливает его после сборки. Нужен доступ на запись в папку установленного Unity. Системные настройки Windows не меняются.

## Управление

Левая кнопка мыши вращает камеру, колесо меняет масштаб. Команды вводятся в игровую консоль.

| Команда | Действие |
|---|---|
| `help` | Список команд |
| `scan` | Названия астероидов в текущей локации |
| `moveto Камень-1` | Подлететь к указанному объекту |
| `mine` / `mine stop` | Начать или остановить добычу |
| `storage` | Груз, вместимость, стоимость и кредиты |
| `warp X Y Z` | Перейти к координатам |
| `warp 420 10 82` | Вернуться к торговому аванпосту |
| `moveto Торговый аванпост` | Подлететь к торговцу |
| `sellall` | Продать весь груз рядом с торговцем |
| `upgrade /?` | Список улучшений |
| `upgrade storage` / `laser` / `quality` / `spotsell` | Улучшить выбранную систему |
| `buyspot` | Три предложения координат залежей |
| `buyspot 1` / `2` / `3` | Купить выбранные координаты |
| `reroll` | Обновить предложения |
| `spots` | Посмотреть купленные координаты |

Неизвестные координаты ведут в пустой сектор. Торговля работает рядом с аванпостом. В редакторе дополнительно доступна команда `location <сид>` и `location sample`.

## Механики

- Залежь содержит 5–6 астероидов одного материала. Первые две цифры сида задают материал, остальные — расположение, форму, размер и расстояния.
- Начальный баланс — 1500 кредитов, вместимость — 500. Один кусок руды занимает 25 единиц, в астероиде 20 кусков.
- Цена и скорость добычи зависят от материала, цены спотов — от редкости D–S.
- Лазер переключается между тремя точками на модели и меняет цвет каждые 5 уровней скорости.
- Груз, улучшения, купленные координаты и исчерпание астероидов сохраняются между переходами в пределах одного запуска. Сохранения на диск в этой версии нет.

Настройки лазера: `Assets/UI/Resources/MiningLaserSettings.asset`.

## Ассеты и проверки

Исходные модели и текстуры находятся в `Assets/ассеты`. Каталог материалов — `Assets/AsteroidMaterials`; сведения об их происхождении — в `SOURCE.md`. Источники скайбоксов: `Assets/LocationSkies/SOURCES.md`.

Редакторские проверки находятся в `Assets/UI/Editor`. `SpaceReleasePipeline.RunBatch` запускает Play Mode проверки и собирает отдельное приложение проверки лазера; его можно запустить скриптом `Tools/verify_mining_player.py`. Проверочный код исключён из обычной сборки.
